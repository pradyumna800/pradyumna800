## 🤖 AI Document Assistant

I'm currently building a **product-oriented AI Document Assistant** based on
Retrieval-Augmented Generation (RAG).

The goal is to build a real deployable AI product rather than just a
proof-of-concept chatbot.

### 🎯 What I'm Building

Users will be able to upload their documents and interact with them through
an AI-powered conversational interface.

### 🔹 Planned / In Development Features

- 📄 Multiple document uploads
- 📚 PDF, TXT and DOCX document processing
- 🔍 Semantic search
- 🧩 Document chunking and embeddings
- 🗄️ Vector database / vector search
- 🤖 LLM-powered responses
- 📖 Retrieval-Augmented Generation
- 💬 Conversational memory
- 🔐 User authentication
- 👤 User-specific document isolation
- 📌 Source citations
- ⚡ Streaming AI responses
- 🌐 Modern web interface
- 🚀 Deployment as a real product
